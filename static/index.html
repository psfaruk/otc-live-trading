    How to get your SSID token
    1. Open qxbroker.com/en/sign-in in Chrome or Firefox
    2. Log in with your Quotex email + password
    3. Once on the trading dashboard, press F12 to open DevTools
    4. Go to Application → Storage → Cookies → https://qxbroker.com
    5. Find the cookie named session (or ssid)
    6. Copy its Value — a long string starting with eyJ…
    7. Paste it above and click Connect

    The token is stored in-memory only and cleared on server restart. It takes priority over the QX_TOKEN env var.
